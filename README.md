# The World Today — 20 November 2026

A make.fun entry for **news-image-20261120**: one image summing up the
world's news of Friday 20 November 2026, as a magazine front page.
The program (`main.py`, Python 3.13, stdlib only, no network) copies
the bundled `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`.
